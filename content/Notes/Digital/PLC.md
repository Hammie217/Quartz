PLC or Programmable Logic Controller is a piece of hardware used to control systems, is is typically built using "Cards" to allow users to define the amount of [[IO]] as per system requirements.
A PLC is typically programmed using IEC 61131-3 standard languages:
- Structured Text
- Ladder Diagram
- Sequential Function Chart
- Function Block Diagram
- Instruction List
